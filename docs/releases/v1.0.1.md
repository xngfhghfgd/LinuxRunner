# LinuxRunner v1.0.1

在你的 iPhone 和 iPad 上运行 Linux。本次更新新增 iPad 桌面适配、把 Arch Linux ARM 纳入安装流程，并改进了包恢复与桌面会话。

## 新功能

- **iPad 支持：** 感知窗口的桌面尺寸、硬件键盘桌面快捷键以及共享的触摸/指针界面。已在实体 iPad 上测试。
- **Arch Linux ARM：** 安装签名包、使用 `pacman`，并体验带 LXQt 面板与 PCManFM-Qt 的实验性 Openbox 桌面。
- **统一的安装流程：** **发行版 → 安装 Linux…** 安装发行版或配置已有环境，同时保留其文件与账户。

维护者报告在**实体 iPhone** 上使用 **build 897** 成功运行了 Arch 图形桌面与图形应用启动。Telegram Desktop 已在 Arch Linux ARM 上完成登录、发消息与通话测试。所附 iPhone 截图展示的是其欢迎界面。

## 改进

Arch 桌面默认提供一个可见面板、壁纸与文件管理器，不会替换用户正常的 LXQt 配置。托管的图形启动共享当前账户的已认证 X11 上下文。组件失败时，桌面启动状态与 Qt 诊断更有帮助。

IPA 打包现包含 ad-hoc 代码签名与标准 ZIP 布局。普通设备安装仍需兼容的签名/描述文件方式。

## 修复

- Arch 终端的 termios2 兼容性。
- 签名缓存包恢复，以及对孤儿 GCC 属主/过期恢复状态的一致处理。
- Qt X11 启动上下文失败与桌面配置默认值。
- 重新打开已有桌面会话，以及组件崩溃后的就绪判断。
- ARM64 vDSO 可执行映射与已覆盖的文件系统/系统调用兼容缺口。

## 支持的发行版

| 发行版 | 体验 |
| --- | --- |
| Debian GNU/Linux 13 ARM64 | 推荐的终端与 LinuxRunner 桌面；KDE Plasma 仍为实验性。 |
| Arch Linux ARM | 终端、`pacman` 与实验性 Openbox/LXQt 组件桌面。 |
| Alpine Linux 3.24 ARM64 | 带 `apk` 的小型终端环境；图形兼容性仍为实验性。 |

## 安装

下载发布版 IPA，并用你偏好的兼容侧载工具（如 Sideloadly 或 AltStore Classic）签名/安装。然后通过**发行版 → 安装 Linux…**在应用内安装 Linux。

参见[安装指南](https://github.com/mxhm11cr/LinuxRunner#installation)与[Linux 安装分步指南](https://github.com/mxhm11cr/LinuxRunner/blob/v1.0.1/docs/GETTING_STARTED.md)。更新时请备份重要文件，并保留已有应用身份与 App Group 配置。不要为了修复问题而卸载应用。

## 已知限制

应用解释执行 ARM64 Linux 用户空间；不启动 Linux 内核、不需要 JIT、也不使用硬件虚拟化。系统调用与应用覆盖不完整。配置的最低要求为 iOS/iPadOS 15.0；机型/系统兼容性不是普适的。iPad 支持已实体测试。较早的 iPhone 11/iOS 17 启动黑屏报告仍未解决。

Arch 桌面、Debian 的 KDE Plasma 与 Metal 加速仍为实验性。Arch 的 Plasma/Wayland 不可用。部分 Arch 的 GTK/glycin 程序仍会遇到写密封兼容问题。大型应用可能较慢或超出内存限制。iOS/iPadOS 可能挂起或终止应用；已保存文件会保留，正在运行的进程无法在终止后存活。

## 下载

- **LinuxRunner-1.0.1.ipa** — ad-hoc 签名，不含 Apple 描述文件。请使用你偏好的兼容签名/侧载方式安装。
- **LinuxRunner-1.0.1-source.tar.gz** — 匹配的应用源码与构建脚本、固定的构建依赖、匹配的 Alpine 源码输入与终端渲染器源码。
- **LICENSES.txt** — 项目与第三方许可证声明。
- **SHA256SUMS** — IPA、源码归档与许可证声明的校验和。

IPA 为 **14,646,386 字节**。请先校验原始下载再签名；签名会改变其校验和。

```text

```

GitHub 自动源码归档不包含子模块内容。含依赖的源码分发请使用单独附带的源码资源。
